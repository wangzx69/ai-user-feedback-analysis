一、这个项目解决什么问题？

不管是游戏运营、内容审核还是美妆品牌，每天都有大量用户评论。人工一条条看：
- 太慢：100条评论要看好几天
- 太主观：每个人分类标准不一样
- 没法规模化：评论多了根本看不过来

我做这个项目就是想验证：能不能用AI把这件事自动化？

答案是：可以。而且效果还不错。
